# 模型凭证

设置环境变量 `MODEL_CREDENTIALS_KEY` 为 32 字节随机值的 base64。凭证使用 AES-256-GCM 保存，每条记录有独立 nonce、认证标签和 key version；数据库备份恢复必须同时保留对应主密钥版本。

轮换流程：部署新主密钥版本，双读旧版本并在明确用户重新保存时写新版本，确认所有旧记录已迁移后撤销旧密钥。缺少密钥时模型功能不可用，脚本 AI 继续运行。日志、WS、DTO 和浏览器存储不包含明文 key。

设置页可编辑和删除既有配置。编辑时 API key 留空保留原凭证，输入新值替换并撤销旧凭证；更换服务地址必须重新提供对应密钥，不自动携带旧密钥。配置、版本及可选凭证在同一事务保存，失败全部回滚。删除采用软删除并撤销凭证，历史版本和调用记录保留。缺少加密主密钥时，页面提前提示并禁止需要写入真实密钥的保存操作。

每次编辑以 expectedVersion 防止旧页面覆盖新内容，新增 immutable profile version。当前尚无完整的对局绑定快照迁移；正在被进行中对局用于模型托管的配置暂时拒绝编辑和删除，须先收回控制。此限制保护现有对局，不代表阶段 6 的版本化绑定、授权撤销 fencing 与预算功能已全部完成。连接测试从单条查询中取得地址、模型、版本及对应凭证，避免并发编辑混用不同服务的密钥。
