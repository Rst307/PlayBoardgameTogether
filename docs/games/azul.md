# 花砖物语

`azul.base@1.0.0` 提供 2–4 人经典彩墙游戏，首局一号座位先手。基础玩法按 [Next Move 官方规则](https://cdn.svc.asmodee.net/production-nextmove/uploads/sites/4/2024/06/EN-Azul-Rules-Next-Move-web.pdf) 实现；不含灰墙变体。桌面与大厅使用原创几何花砖。

## 操作与计分

创建房间选择「花砖物语」，可邀请真人或添加基础脚本 AI。轮到自己时，选择一个工厂或中央的某色整组，再点高亮图案行，最后「确认选砖」。不能拆行；溢出进入地板，也能「全部放地板」。确认前可取消或按 Escape。工厂剩余颜色进入中央，首次从中央拿砖附带先手标记。

两/三/四人使用 5/7/9 个工厂，每轮每个补四砖。图案行容量 1–5，仅接受同色且对应墙行尚未铺该色，满行不能追加。砖源取空后从上到下自动铺墙，保留未满行。计分按连续水平和垂直长度独立计算，两方向都有连线时新砖计两次。地板扣分为 1/1/2/2/2/3/3，最低零分；满地板后砖直接弃置，先手标记仍指定下轮先手。袋空回收弃砖，不足允许工厂未填满。

任意完整横行触发本轮结束后的终局奖励：横行 +2、竖列 +7、同色五砖 +10。同分比较完整横行数，仍相同共享胜利。

## 交互教程

游戏详情点击「进入教程」，或访问 `/games/azul.base/1.0.0/tutorial`。八个独立练习覆盖工厂整组选砖、同色续填与墙面限制、溢出、中央先手标记、轮末铺墙与未满行保留、交叉六分、地板最低零分、终局横行/竖列/同色奖励。无需登录，不创建房间或保存真实成绩；支持重试、上一步和重新开始，刷新从头开始。

教程复用正式花砖桌面和公开计分事件，练习也会播放落砖、连线和奖励动画。仅发布固定公开 View 与事件，不包含袋/弃砖内容或权威 State；不调用正式动作 API。每课用单元测试逐帧核对正式规则，素材由 `pnpm exec tsx scripts/generate-azul-tutorial.ts` 生成，入口为独立 `@boardgame/azul/tutorial` 导出。当前教程不接入全站对局音效播放器。

## 得分表现

2026-10-03 地板显示修正：最后一组选砖触发轮末结算时，仍显示本轮待扣分的花砖和先手标记，直到该玩家的地板扣分动画完成后清空；图案行溢出同样保留。显示使用公开 View 与 live 选砖事件，不修改权威计分；刷新和重连只显示当前地板，不补播历史。

花砖物语声明客户端 `finishBehavior: 'stay'`：最后一轮会保留游戏桌面、终局奖励和获胜名单，主动点击「返回房间」再准备下一局；服务端已经在原事务内恢复房间 waiting。

公开 `round.scored` 投影事件提供每次落砖、连线格、名义增减、实际前后分数与奖励明细。客户端先落砖停顿 300ms，再按横线/竖线各 800ms 分段计算，最后保留结果 600ms：交叉六分会在墙面附近依次弹出「+3」「+3 +3」，分数从原值逐步增加，相应墙线依次闪光。完整竖列等多项奖励拆成「+7 +7 +7」。单项约 1.7 秒、交叉连线约 2.5 秒；文字放大弹动、回弹，随后上飘淡出并移除，不保留固定计分条、板内算式区或等号总计。飘字不占布局、不拦截点击；读屏仍获得分步计分与实际扣分通知。

拆分仅消费公开事件，必须合计等于权威增减；无法解释的几何数据直接展示事件原值，地板分数最低零，名义与实际扣分可查看最近一轮明细。动画期间可继续操作，不改变规则、事件协议或权威分数。队列有界，计时器卸载清理；系统「减少动态效果」隐藏飘字、禁用移动和碎光，直接显示结果并在 180ms 后推进。刷新只展示墙面、分数和最近一轮明细，不补播历史。

2026-10-03 计分移动修正：待结算的满图案行保留，按行将最右侧一砖从左侧实际位置飞入右侧墙格（300ms）；途中目标格为空、分数不变。落位后其余弃砖淡出（180ms），再播放上述连线与分步加分。待结算行暂时不能再次选择，完成后恢复最新权威行；其他可用行仍可操作。飞行层不占布局、不拦截点击，按实际桌面/手机格子坐标移动，ResizeObserver 卸载清理。减少动态效果时直接落位。

声音沿用全站 AudioManager，先点击「启用声音 / 测试声音」。原创瓷砖短音用于确认选砖、移砖和地板扣分；上升和弦跟随落位加分、横/竖连线及终局奖励，胜利和弦在全部结算动画完成后播放。复用本局锁定资源包已有 draft/score/finish 映射，不更换旧包或改写资源字节。平台只授权已去重的 WS live 事件；静音、断线、后台、标签页主控变化及卸载令尚未播放的节拍失效，稍后启用声音不会补播。快照、HTTP 回执、刷新与重连不授予播放权限；教程没有正式音效回调，保持静音。

## 维护

包 shared/server/client/rules/assets 导出分离。客户端只获得公开玩家板、砖源、袋数量和本身份合法候选，不含袋顺序或弃砖内容。恢复校验每色二十砖守恒、图案行、座位、先手与终局。AI 根据 View 和候选偏好满行/连线、减少溢出，仍走既有动作事务。

安装：`pnpm install --frozen-lockfile`、`pnpm games:sync`、`pnpm assets:seed`，然后重新加载 API/Web。游戏不需要新数据库迁移。生成音频存入既有资源目录，不提交 WAV 或数据库内容。游戏包 build 复制 CSS 到 dist。实际验收与边界见 [开发进度](../progress.md)。
