# 卡坦岛

经典基础版通过 `online.catan@1.0.0` 在线 ZIP 接入，3–4 人，支持真人和基础脚本 AI。包括起始摆放、骰子生产、强盗/弃牌/偷取、道路/聚落/城市、港口与玩家交易/还价、全部五类发展牌、最长道路、最大骑士军和自己回合 10 分终局。

运行 `node scripts/package-catan.mjs`，管理员在游戏管理上传 `dist/game-packages/catan-1.0.0.zip`、检查并审核后上架。无需新迁移或重启；未上传环境没有大厅入口。正式安装不是本地打包或测试库验证的一部分。

海蓝岛屿棋桌保留棋盘和本人资源，复杂操作进入弹窗；点选后确认，手机可放大/拖动和用位置列表选择。私密资源组成、发展卡和牌堆不公开，刷新与回放复用平台原链路。规则来源、数字版选择、维护及限制见 [卡坦岛上传包](../../game-packages/catan/README.md)。
