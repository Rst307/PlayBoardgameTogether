# Grid Garden

`grid-garden@1.0.0` 是 2–4 人、三轮、同时秘密选择与独立空间放置的原创验收游戏。每人拥有 4×4 棋盘和 3 点初始能量。

每轮在 `selecting` 阶段提交一次 `harvest` 或 `build`。提交后不可修改；全员提交前只公开 `hasSubmitted`，能量和他人选择均不变化。全员提交的同一次动作事务统一公开：收获增加 2 能量，建造扣除 1 能量。若无人建造则自动进入下一轮。

`placing` 阶段只等待本轮建造者。横向骨牌覆盖 `(x,y)` 与 `(x+1,y)`，纵向覆盖 `(x,y)` 与 `(x,y+1)`；越界、重叠和重复放置均拒绝。不同玩家棋盘独立。最后一名建造者落子时自动推进轮次。

第三轮结束后，分数为占用格数加 `floor(剩余能量 / 2)`，所有最高分玩家共同获胜。正式动作继续使用 `requestId`、`expectedRevision` 和 `expectedControllerEpoch`；seat 只来自 session 对应的固定参与者。

脚本策略在可建造时选择建造，否则收获；放置按 y、x、H 优先于 V 的稳定顺序选择。模型只收到本人 View、公开规则和枚举后的 choiceId，不读取内部 State。

资源契约包含棋盘、骨牌、能量/收获/建造图标，以及 reveal/place/finish 三类短音效。资源缺失时语义棋盘仍可操作；图片与声音不参与合法性和计分。

操作：点击收获或建造提交本轮选择；成功后本人会看到锁定的具体选择，对手仍只看到提交状态。明确冲突后保留本轮行动草稿，检查最新局面后再次点击按钮提交；结果未知时使用平台“确认操作结果”查询或重试原请求。

建造时先选横向 H 或纵向 V，再点击棋盘起点、检查两格预览并确认放置。越界和重叠分别显示文字原因。键盘通过 Tab 进入本人棋盘，用方向键移动焦点，Home/End 到行首/行尾，Ctrl+Home/End 到棋盘首尾，Enter 或空格选择起点。其他玩家落子后本人预览仍保留；本人落子成功或进入新轮后清除旧预览。
