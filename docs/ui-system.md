# 界面系统

## 游戏目录与详情（2026-10-02）

首页使用游戏封面卡片，呈现真实已启用目录中的名称、简介与人数；不展示虚构推荐、热度或开发实验台。详情页将封面、游戏说明与创建/加入操作置于主区域，加入区按需展开，集中放邀请码与当前游戏公开房间。创建带入所选版本；缺失游戏有明确反馈与返回路径。封面为原创几何 SVG，配色按目录 ID 稳定生成；沿用中性灰、宋体/Georgia 标题、系统蓝交互与键盘焦点。`catalog.css` 最后加载，仅作用于目录/详情类名。桌面卡片自适应分列，700px 以下详情单列，保留 44px 操作入口与自然滚动。

## 平台基础与界面原则（2026-10-02）

按 [项目优化审查](project-optimization-2026-10-02.md) 的层次、一致性、状态可见、防错恢复、用户控制和可访问适配六项原则维护。页面标题随导航更新；页面文件按需加载并由外层错误边界提供恢复，站点导航保持可用。登录允许显式显示/隐藏密码，请求中锁定表单，错误分别说明凭据、频控或连接失败；失败保留输入，卸载后不执行迟到导航。404 提供大厅与文档入口；图标与浏览器主题色沿用当前灰阶系统。短桌面侧栏可滚动到所有导航项，手机保留原布局。

## 大厅与资料入口（2026-10-01）

主导航只列游戏大厅、我的资料，创建入口位于大厅标题区并进入独立建房页；建房页提供返回大厅。继续游戏和邀请码加入为两块辅助区域，公开房间保留筛选和分页。退出登录放在资料页。按钮文字统一 line-height/text-align，普通按钮与按钮样式链接使用 flex 居中，房间行使用垂直居中；保留卡牌/棋盘专属布局。资料为桌面双列、手机单列，包含内置头像单选、可选中完整账户 ID、昵称/简介和真实对局历史。

2026-10-01 渐进动效与无刷新换页：站内页面链接通过现有 history 路由切换，侧栏保持挂载；内容区域使用 140–220 ms View Transition 交叉淡入，不支持该 API 时仍无刷新切页并短淡入。换页立即禁用离开页面的交互，新页面将焦点移至主要内容；主动导航回到顶部，浏览器前进/后退沿用原生滚动恢复。外部链接、修饰键、新窗口、下载与锚点保持浏览器语义。减少动态效果时直接切页。房间列表、座位、资源与花园面板错开 40/80/120/160 ms 入场，后续项封顶以避免长等待；已有节点的实时更新不重新入场。

第九阶段沿用 React、原生表单与 CSS，无新 UI 框架。2026-10-01 按 [macOS Vibrancy 参考](https://www.stylekit.top/zh/styles/macos-vibrancy) 全站改版：`stage9.css` 提供中性灰基础与既有响应式布局，`apps/web/src/styles/vibrancy.css` 最后加载，负责桌面侧栏、工作区及组件统一。卡牌颜色、棋盘状态与图包仍使用游戏自身语义。

| 变量 | 用途 |
| --- | --- |
| --bg / --panel / --panel-raised | #1c1c1e / #2c2c2e / #3a3a3c 三级中性深灰 |
| --text / --muted / --line | 正文、辅助文字、可辨认边界 |
| --accent / --accent-soft | #0a84ff 焦点/交互强调色；行动提示使用中性次级表面 |
| --control-line | #858589，表单与本人棋盘的可辨认边界；装饰分隔仍使用 white/10 |
| --success / --warning / --danger | 成功、警示、错误；同时提供文字 |
| --space-1 至 --space-6 | 4/8/12/16/24/32 px 间距 |
| --radius / --shadow / --duration | 最大 12px 圆角、1px 轻阴影、200 ms 控件过渡 |
| --motion-enter / --motion-ease | 360 ms 页面入场与共享缓动；仪表盘面板错开 70 ms |
| --layer-nav / --layer-focus | 导航菜单与键盘跳转入口层级 |

正文使用本机系统无衬线字体，标题使用 Georgia / 宋体衬线字体，代码使用 SF Mono / Menlo / Consolas；不下载外部字体。数字使用 tabular-nums。标题随宽度缩放，房间名可换行。焦点使用 2px 系统蓝轮廓，主按钮及表单至少 44px 高。表单边界比参考的装饰线更亮，以保留控件可辨认性。

桌面为 228px 半透明模糊侧栏与工作区，701–1100px 收窄侧栏并将复杂内容变成单列；700px 以下使用顶部导航及可展开的更多菜单。顶部路径栏随页面变化，侧栏项使用 aria-current 标识。平台表面保持纯灰；2026-10-01 后续调整增加标题/登录卡淡入上移、面板错峰入场、按钮按压、导航图标反馈、展开内容淡入和选牌抬起。不使用持续循环动画，游戏规则颜色与图片独立保留。

下拉框、选项、复选框、单选框、音量滑块和文件选择按钮统一使用灰阶表面、控件边界和系统蓝。下拉框保留原生 select 的表单、键盘及辅助技术语义；支持 `appearance: base-select` 的浏览器同时显示主题化选项菜单，不支持时回退原生菜单与统一箭头。强制颜色模式恢复原生选择控件。声音设置的静音标签提供至少 44px 点击区域。

`packages/ui` 的 Button、Panel、StatusBadge、ErrorNotice 保留。新增 PageFeedback（加载/失败/重试）、ActionHint（必要状态播报）和 GameErrorBoundary（仅隔离扩展绘制）。边界内部由 GameSurface 调用游戏渲染器，解析或绘制抛错不会移除返回房间入口。

手机主要区域自然滚动，不设遮挡内容的固定底栏。Color Match 手牌局部横向滚动，卡面含颜色文字、数字及可出/不可出/已选中。Grid Garden 优先显示自己的花园，公开对手棋盘缩小后放侧栏或下方。本人交互格保留方向键/Home/End 和 Enter/Space。

更多导航、控制方式、声音、说明使用原生 details/summary；没有自制 modal、焦点陷阱或拖拽依赖。危险关闭仍用浏览器确认，影响文案和服务端权限保持。页面通过跳到主要内容入口支持键盘访问。

选择/预览属于本地草稿；保存和阶段转换等待服务端事实。公开行动记录使用短淡入，live 去重仍在 MatchPage。恢复不向记录补入历史事件。系统 prefers-reduced-motion 禁止动画/过渡并取消选牌位移；触屏不启用悬停抬起。音效继续只经 AudioManager，不参与动作完成判断。

验收尺寸：320×568、390×844、844×390、768×1024、1440×900。必要对比和触摸目标检查见阶段 9 验收；不宣称无障碍认证。移动设备模拟与真实软键盘/物理设备验收分开记录。

## 游戏优先与结算返回（2026-10-02）

游戏桌页使用紧凑顶部导航，宽屏将游戏桌作为主列、规则/声音/控制方式/座位控制状态作为辅助列；1100px 以下辅助内容移至游戏桌下方。辅助面板沿用可展开的原生 details，游戏操作和连接/保存/错误反馈优先可见。共享 usability.css 最后加载，保留既有灰阶配色、游戏语义颜色、44px 点击区域、键盘焦点和减少动态效果偏好。

正式页面观察到 active → finished 后自动回原房间，保留成员和席位，提示重新准备并提供本局结果链接。直接打开或刷新历史 finished 对局继续只读查看结算，不自动跳转。关闭房间仍按既有权限流程回大厅。结果未确认或连接未恢复时禁止新的游戏动作和控制方式切换；房间写入期间提示保存中。


## 璀璨宝石紧凑棋盘（2026-10-02）

splendor.css 仅针对该扩展及包含其桌面的 match-page 调整布局：深绿桌面、金色回合／选择标识、按视口高度限制卡面、库存与贵族并排、四列三层市场、可滚动商会侧栏。经典卡面额外显示 View 中的语义声望／折扣／费用，手机点击卡牌可放大查看。通用按钮多重 :not 选择器曾覆盖游戏间距，游戏控件使用明确限定的选择器修复，不改变其他游戏样式。

宝石点击从同一交互组合三色或同色双拿，非法原因直接显示；确认面板允许逐枚移除草稿，支持 Esc。轮到其他人时卡牌仍可查看，提交按钮保持权限／阶段禁用。保存反馈不再占据棋盘垂直空间；公开行动在视口内展示五秒，买牌卡面带短进入动画；日志保留真实公开事件，不展示私密预留，不补播刷新历史，计时器在事件替换或卸载时清理。
