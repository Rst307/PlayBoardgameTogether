# ADR-010：可选官方游戏订阅

状态：Accepted，2026-11-01。

用户要求自动添加和更新游戏，并明确选择官方游戏目录。既有 ZIP 管理流程要求每次上传检查、审核后发布，不足以持续跟踪独立游戏仓库的 Release；内置游戏仍依赖平台构建，不能宣称支持热更新。

在管理员游戏管理页提供默认关闭的「自动添加」和「自动更新」。管理员保存时，明确授予所选范围内的官方 ZIP 持续安装授权；无需每次再人工上传审核，也不依赖浏览器或保留会话 token。授权绑定保存者，提交安装时复验该账户仍为活跃管理员以及原策略 revision；停用/改权/删除会阻止后续安装。其他管理员可重新保存授权。

固定信任 PlayBoardgameTogether 平台 main 的官方游戏目录及同组织登记仓库的正式 Release。使用既有发布工作流的 release.json、SHA-256 和精确 ZIP，不支持任意 URL、源码包或宿主执行。摘要用于检测下载与清单不一致，不声称能抵御官方发布账户或仓库被攻破。普通手动上传继续使用原逐包审核和有效会话。

后台每小时检查，可手动触发，复用现有 API 进程和 PostgreSQL 会话锁串行调度；逐包进入原 GamePackageService 安装事务，保留目录摘要并发检查、不可变版本和旧局恢复。已下架游戏不重新上架，不降级，内置游戏不进入该链路。跨游戏不是一个事务，结果如实报告成功、跳过和失败项。

新迁移仅持久订阅策略和最近结果；管理员配置及手动请求继续使用原 AdminService 回执，不另建身份或管理员命令流程。退出时取消任务，异常退出释放数据库锁并由下次到期/手动同步恢复。安装器既有容量限制和旧版本保留要求继续适用。

细节与操作见 [官方游戏订阅](../game-subscription.md)。
