作者：桌游平台。许可：CC0-1.0。来源：`scripts/seed-assets.ts`。

PNG 使用逐像素原创边框、圆点、菱形和棋盘纹理；WAV 为低增益正弦波与短包络。不使用商业游戏素材、下载字体或外部音频。逻辑颜色与数字仍由可访问文字提供，图包不改变玩法。

运行 `pnpm assets:seed` 将真实文件经媒体解码校验后写到独立持久资源目录及数据库；不会写进前端 public。旧 default@1.0.0 空清单保持原样，供历史 CSS 对局恢复。
